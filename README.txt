ORDER App — แยกไฟล์

โครงสร้าง:
- index.html : โครงสร้างหน้าเว็บ
- css/style.css : CSS ทั้งหมดจากไฟล์เดิม
- js/app.js : JavaScript ทั้งหมดจากไฟล์เดิม (คงลำดับเดิม)

ไลบรารีภายนอกยังโหลดจาก CDN เหมือนเดิม:
- SheetJS
- JSZip
- html2pdf.js

หมายเหตุ: ไฟล์เดิมอ้างถึง bank.jpg เป็นภาพพื้นหลัง หากมีไฟล์ bank.jpg ของเดิม ให้วางไว้ข้าง index.html เพื่อให้พื้นหลังเหมือนเดิม
